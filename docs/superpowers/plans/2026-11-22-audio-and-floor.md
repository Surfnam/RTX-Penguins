# Audio System and the Ice Cave floor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add state-aware music and SFX to RTX Penguins and generate one new unique frozen-cave floor.

**Architecture:** A runtime-created `AudioManager` singleton loads clips from `Resources/Audio` by name, plays SFX through a pooled one-shot source, and crossfades music between two sources driven by a small pure `MusicStateResolver`. Gameplay scripts call `AudioManager.PlaySfx(name)`; a missing clip is a silent no-op. the Ice Cave floor is generated by an editor menu script in the same style as `LevelBuilder`.

**Tech Stack:** Unity 6000.0.82f1, URP, C#, Unity Test Framework 1.6.0 (project convention is editor self-check scripts run via menu or `-executeMethod`).

**Spec:** `docs/superpowers/specs/2026-11-22-audio-and-floor-design.md`

## Global Constraints

- Commits: one short sentence each, no Claude/Anthropic mention, no trailers.
- Work only on branch `audio-and-level` (based on `origin/main`); do not depend on PRs #9/#10.
- Clips load via `Resources.Load<AudioClip>("Audio/SFX/<name>")` and `"Audio/Music/<name>"`; missing clip never throws.
- `AudioListener.volume` (menu slider) must keep controlling master volume; do not add another master control.
- Music: Blue Lava "Melodic Winter" (CC BY-SA, credit required). SFX: Kenney (CC0). Credits go in `README.md`.
- No Unity editor in the authoring environment: code cannot be compiled here; each task ends with a Unity-side check.

## Review Focus

- Player dies while a stinger or crossfade is mid-way: music returns to Explore, no overlapping tracks.
- Win/Lose menu sets `Time.timeScale = 0`: stinger and crossfade must still advance (use unscaled time).
- Scene reload (menu "Retry") must not create a second `AudioManager` or double the music.
- Music zip not yet added: game runs silent for music, SFX still work, no errors.
- Pause (Esc) must switch to menu music and back to the prior state on resume.
